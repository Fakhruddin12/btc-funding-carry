# Cost-Aware BTC/ETH Spot-Futures Trading

This study asks whether a spot-futures premium pays for trading costs and the return available on cash. It uses a matched spot/inverse-futures hedge and a fixed entry filter. The latest saved research snapshot is dated 25 October 2026.

## Results

| Dated-futures evaluation, January 2023-June 2026 | Net total return | Annualised return |
|---|---:|---:|
| Fixed cost and cash filter | 19.35% | 5.20% |
| Every eligible trade | 16.81% | 4.55% |
| Cash proxy | 16.79% | 4.55% |

The filter reduced trading costs by 67%. These total returns include cash interest. Excess returns are modest, opportunities are limited and execution costs are assumptions rather than reconstructed quote-to-fill outcomes.

## Reproduce

Run these commands from this directory using Python 3.11 or newer. The archived environment and pinned packages are recorded in `requirements.txt`.

```bash
python extract_inputs.py
python verify_inputs.py
python -m pip install -r requirements.txt
python -m pytest -q tests
python carry.py --phase development
python carry.py --phase locked
python inverse.py
python robustness.py
python diagnostics.py
python build_report.py
```

The snapshot is stored in small checked parts under `inputs/`. `extract_inputs.py` verifies and reassembles `research-inputs.zip` before extraction. The compressed snapshot contains the processed ETF, spot, perpetual, funding, dated-futures and cash inputs used by the saved run. `INPUT_SNAPSHOT.json` records every input's size and SHA-256 hash. No API key is needed. The original monthly/daily source ZIP files are not duplicated in this GitHub edition. Their URLs and hashes remain in the source manifests and the original downloaders can retrieve them. Re-downloaded archives may change, so verify hashes before treating a fresh download as the same data vintage.

Large hourly result ledgers are regenerated by the scripts. The repository includes the final summary tables, order/episode records and audit evidence. Some report references describe the larger original research release, including raw archives and superseded exploratory notebooks. They do not imply that every original intermediate file is duplicated here.

## Trading rules and accounting

The dated-futures strategy tests all 44 BTC/ETH quarterly expiries from 2021Q1 through 2026Q2. It makes the decision 60 days before expiry from completed information and uses 24 hourly slices to enter and exit. The participation cap is 1% of prior mean hourly notional volume on each leg. The entry hurdle covers four-leg base costs, cash opportunity cost and a 2% annual risk buffer. Rejected allocations remain in cash.

The inverse short is collateralised by matched coin. Contracts are integers, spot lots are rounded to 0.001 coin, fees are charged in the correct currency and residual coin dust stays in the ledger. A USD 1 million trial failed an unwind check. The supported dated-futures prototype starts at USD 100,000.

The separate funding study uses matched spot and linear perpetual positions. It compares always-on, an EWMA funding filter and a Ridge forecast. Posted margin earns no interest, and futures gains cannot create fictitious free cash. The cash proxy is lagged SOFR minus 25 basis points, floored at zero.

## What kind of test is this

The data are ordered in time and signals precede fills. The funding choice came from 2022 validation. Later preliminary results had been inspected before uniform execution and cash-benchmark corrections, so the final later-period results are retrospective chronological evaluations, not pristine unseen holdouts. The declared selection was retained rather than choosing a new winner from later results.

`trial_ledger.csv`, the protocol files and `crypto_locked_decision.json` document the research history. Earlier ETF models failed their 2019-2021 validation and their later strategy test stayed unopened. Earlier equity-pairs results are retained as failed research, with no headline Sharpe claim.

## Limitations

The base costs are 12 basis points for spot and 7 for futures per side, with higher-cost stresses. Actual depth, queues, asynchronous legs, transfers, exchange failure, stablecoin depeg, taxes and ADL are not reconstructed. OHLC margin checks are conditional evidence. The study does not establish live profitability or large-capital capacity.

The original release inventory is archived in `docs/ORIGINAL_RELEASE_CONTENTS.json`. It describes the larger historical release rather than this GitHub package.

Source code and the frozen funding identity are unchanged from the archived research snapshot. Packaging, this README, the input verifier and the results evidence map were added for publication.
